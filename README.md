# PayPal Checkout Platform

A production-style microservices application built to learn and demonstrate Azure DevOps, Docker, Kubernetes, Helm, and CI/CD.

---

## Project Overview

This project simulates a simplified PayPal checkout workflow using microservices deployed on Azure Kubernetes Service (AKS).

The application consists of:

- Frontend
- Authentication Service
- Payment Service
- Notification Service

Each service runs inside its own Docker container and is deployed independently on Kubernetes.

---

## Technology Stack

- Python Flask
- Docker
- Azure Container Registry (ACR)
- Azure Kubernetes Service (AKS)
- Kubernetes
- Helm
- GitHub Actions
- Azure CLI
- Git
